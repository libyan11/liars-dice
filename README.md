# Liar's Dice

## ▶ [Play the game](https://libyan11.github.io/liars-dice/)

https://libyan11.github.io/liars-dice/

Liar's Dice in your browser, on phone or computer. Play online with friends, or against the computer. Part of [Game Night](https://libyan11.github.io/).

**Play with friends:** one person taps *Create a room* and shares the 4-letter code or link. Everyone else types the code and taps *Join room*. 2 to 6 players, and the host can fill empty seats with computer players. If someone drops out, the computer plays for them until they come back.

**Rules**
- Everyone has 5 hidden dice.
- A bid says how many dice of one number are on the whole table, like "at least 4 fives".
- Each bid must be higher: more dice, or the same number of dice with a higher number.
- Instead of raising, call "Liar!". If there are at least as many as bid, the caller loses a die; otherwise the bidder does.
- Optional: 1s are wild and count as any number (you can't bid on 1s then).
- The loser bids first next round. Run out of dice and you're out; the last player with dice wins.
